# Projeto-TCC-Senai
O objetivo desse repositório é conseguirmos resolver uma demada selecionada no Saga Senai para elaboração do nosso TCC
GESTÃO E TRATAMENTO DE DADOS PARA PESQUISA DE SATISFAÇÃO DO CLIENTE 
Descrição resumida:
A empresa realiza atendimentos contínuos ao cliente, porém ainda não possui um processo estruturado para mensurar, consolidar e analisar a satisfação em seus setores através de uma pesquisa de satisfação do clientes. A ausência de dados organizados compromete a visão gerencial, dificulta a identificação de falhas específicas (caixa, atendimento, ambiente, etc.) e impede decisões baseadas em evidências.


Benefícios esperados:
Visibilidade clara do nível de satisfação do cliente
Identificação objetiva de pontos críticos por setor
Redução de retrabalho e reclamações recorrentes
Base concreta para tomada de decisão gerencial
Fortalecimento da cultura de melhoria contínua
Aumento da fidelização e competitividade

Detalhamento:
Atualmente, a empresa não dispõe de metodologia padronizada para coleta e análise de dados relacionados à experiência do cliente. As avaliações ocorrem de forma informal, sem segmentação clara por setores e sem consolidação estatística que permita acompanhamento periódico.

Não há indicadores consolidados que permitam:
Comparação de desempenho entre setores (ex.: caixa, atendimento, ambiente físico) Avaliação de tendência ao longo do tempo
Identificação de queda de desempenho antes do aumento de reclamações
Correlação entre atendimento e fidelização.

Além disso, a empresa não possui visualização estruturada das informações para acompanhamento gerencial, o que limita a leitura estratégica do desempenho e impacta diretamente a competitividade.

Escola:
(MG) SENAI Ituiutaba CFP Bebé Martins

Restrições (O que a solução não pode ter):
Não pode gerar coleta de dados sem conformidade com LGPD
Não pode depender exclusivamente de ferramentas de alto custo
Não pode ser excessivamente complexo para uso operacional
Não pode demandar equipe técnica especializada permanente
Não pode gerar relatórios pouco intuitivos ou de difícil interpretação

Estado:
MG

A linguagem que utilizaremos para esse trebalho é JAVA
